# Hatch

## Build messily. Publish cleanly.

Hatch is for solo makers who need room to explore without making every draft
ready for the public.

Keep a complex, private workbench for unfinished ideas. Keep a clean product
space for what is ready to share. When work crosses that boundary, Hatch turns
the promotion into an explicit brief, checks public-safety risks, and connects
the decision to real evidence.

Start a project with Hatch and it creates separate local workbench, product,
and eval repositories—each with its own Git history and no remote by default.
When a version is ready, Hatch records it in `VERSION` and `CHANGELOG.md`, then
audits files, paths, Git identities, and commit messages before the final
public-readiness check.
